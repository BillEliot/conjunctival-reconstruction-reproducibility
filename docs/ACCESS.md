# Data and model access

| Material | Access in this repository |
|---|---|
| Public-record Dice and other scalar results | Included in `software/data/` |
| Reconstruction and analysis code | Included in `software/` |
| Training and inference implementation snapshots | Included for inspection in `software/frozen_source/` |
| Four qualitative public photographs and references | Included under the source CC BY 4.0 license |
| Four sets of saved prediction masks | Included for figure checks |
| Institutional performance summaries | Included as aggregate figure inputs and manuscript tables |
| Institutional photographs and annotations | Unavailable for sharing or access requests |
| Trained model weights | Unavailable for sharing or access requests |
| Full public prediction probability arrays | Not included; original server checks are retained as receipts |

Hospital-imposed confidentiality and ethical restrictions govern institutional photographs, annotations and trained weights, including confidential editorial access. The authorized exception covers this code and scalar-result release. No request route is offered for the restricted materials.

The public source dataset is Eyes-defy-anemia, https://doi.org/10.21227/t5s2-4j73 . Its original license metadata are retained in `data/qualitative/dataset_metadata.json`; the article describing the dataset is https://doi.org/10.1016/j.artmed.2022.102477 . The repository contains four illustrative records, not a replacement distribution of the entire dataset.
